# NAI 创作偏好

这份文件放在写提示词用的工作区根目录。「NAI5 提示词」模式的每个会话都会自动读入它，上下文压缩后也会重新读入。只写长期有效的偏好；某一张图的要求直接在对话里说。

## 固定偏好

- 默认模型：V5 Full
- 写提示词时用的语言：英文为主，长句可以写中文

## 【完全模仿】

技能只会原样使用这一节里给出的完整画师串（顺序、权重、空格、年份都照抄）。名字列表或频次表不算配方。没有固定串就删掉这一节。

```
<把你的完整画师串贴在这里>
```

## UC

## OC 库

- 设定文件放在 `oc/` 目录，一个角色一个文件，例如 `oc/角色名.md`。
- 用到某个角色时先读对应文件；一次性的换装不写回设定文件。
- 让它新建或更新设定时直接说，例如“把这个角色存进 OC 库”。
